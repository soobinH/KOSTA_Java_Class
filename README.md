# Java Theory Study (3-Week)

> KOSTA "AI를 활용한 Java 기반 풀스택 개발자 양성과정" 중 초반 3주간 진행한 자바 이론 학습 기록 레포지토리입니다.
> 교재는 **『자바의 정석』(남궁성 저)** 을 기준으로 진행했으며, 챕터별 핵심 개념 정리와 실습 예제 코드를 담고 있습니다.

## 소개

이 레포지토리는 국비지원 교육과정(KOSTA) 내에서 진행한 Java 이론 파트를 정리한 공간입니다.
처음 Java를 배우는 과정은 아니었지만, 실무에서 사용하던 지식을 체계적으로 재정리하고 기초를 다시 다지는 목적으로 3주간 집중 학습했습니다.

- **교재**: 자바의 정석 (Chapter 1 ~ 14 기준)
- **기간**: 3주
- **학습 방식**: 이론 강의 → 예제 코드 실습 → 개념 정리(README/주석) → 확인 문제 풀이
- **목표**: 실무 경험을 이론적으로 뒷받침하고, 언어 스펙에 대한 이해도를 높이는 것
